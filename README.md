# Splitbon project website

Static German project website for [Splitbon](https://github.com/cyborcc/splitbon).

Published at https://cyborcc.github.io/splitbon-website/ through GitHub Actions and GitHub Pages. No dependencies or build step. Edit `index.html` and `styles.css`; pushing to `main` deploys the page.

This is a project presentation and self-hosting guide, not a hosted SaaS service or commercial checkout. No analytics, visitor forms or secrets. Product demo media comes from the main Splitbon repository. The receipt in the hero is explicitly illustrative.

Before adding a commercial offer, use hosting whose terms allow it. Before collecting personal information, configure a real submission backend and update the privacy notice. The owner should assess and add any required legal publisher information before operating a commercial website.

For a custom domain, verify ownership in GitHub, set the Pages custom domain, then configure DNS and HTTPS. Update canonical and Open Graph URLs, `robots.txt` and `sitemap.xml`. A domain is not required for the github.io URL.
